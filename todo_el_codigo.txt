# GuÃ­a del Proyecto (Nota para el programador)

Hola pana del futuro, seguro entraste aquÃ­ despuÃ©s de un tiempo y te estÃ¡s preguntando para quÃ© diablos sirven tantos archivos y carpetas. Tranquilo, todo estÃ¡ separado para no volver a tener un `App.jsx` gigante e imposible de leer. 

AquÃ­ tienes el mapa completo de dÃ³nde estÃ¡ cada cosa:

---

## 1. Recursos Visuales y Audio (`public/assets/`)
AquÃ­ van todos los archivos multimedia limpios (imÃ¡genes y sonidos):
* **`public/assets/sprites/player/sprites.jpg`**: La hoja de sprites principal de tu personaje (caminatas y ataques).
* **`public/assets/sprites/npcs/`**: Sprites de los personajes secundarios (estÃ¡ticos o animados).
* **`public/assets/sprites/bosses/`**: Sprites de los jefes y sus proyectiles/ataques.
* **`public/assets/sprites/objects/`**: Cofres, bloques empujables y decoraciÃ³n de los cuartos.
* **`public/assets/backgrounds/`**: Fondos dibujados para reemplazar los colores planos de cada sala.
* **`public/assets/ui/`**: ImÃ¡genes de interfaz, como el diseÃ±o de `mapa.png`.
* **`public/assets/audio/music/song.mp3`**: La mÃºsica de fondo principal.
* **`public/assets/audio/sfx/`**: Efectos de sonido cortos (pasos, espadazos, abrir cofres, voces de diÃ¡logo).

---

## 2. El Contenedor Principal (`src/App.jsx`)
Es el caparazÃ³n visual de React. **No tiene lÃ³gica del juego**, solo se encarga de:
* Montar el `<canvas>` donde se dibuja todo a 60 FPS.
* Escuchar el teclado (`WASD`, `E`, `Tab`, `M`) y el ratÃ³n.
* Mostrar la leyenda de controles en PC o los botones tÃ¡ctiles (D-Pad, `E`, `ATACAR`, `MAPA`) cuando se abre desde un celular.
* Bloquear el clic derecho y el menÃº contextual del navegador (lÃ­nea 324) para que no estorben al jugar.

---

## 3. El Motor del Juego (`src/game/`)
Toda la lÃ³gica pura vive aquÃ­ dividida por responsabilidades:

* **`constants.js`**: El archivo de configuraciÃ³n. AquÃ­ estÃ¡n las medidas del canvas, velocidades, vidas mÃ¡ximas, colores de las salas y **las coordenadas exactas `[fila, columna]` de los sprites de tu skin segÃºn cada direcciÃ³n de movimiento y ataque**.
* **`assets.js`**: El cargador de imÃ¡genes. Importa las hojas de sprites y ejecuta la funciÃ³n que borra el fondo negro exterior automÃ¡ticamente antes de dibujarlas.
* **`audio.js`**: Controla la mÃºsica de fondo (`song.mp3`), el muteo con la tecla `M` y los futuros efectos de sonido (SFX).
* **`state.js`**: La memoria de la partida. Define dÃ³nde empieza el jugador, cuÃ¡nta vida tiene, el estado de los cofres/enemigos y las funciones para **guardar y cargar partida** en `localStorage` (checkpoint en el cuarto sur).
* **`physics.js`**: Las matemÃ¡ticas de colisiÃ³n. Calcula las cajas de impacto (*hitboxes*) del jugador, la espada, enemigos, cofres y NPCs, ademÃ¡s de detectar si estÃ¡s lo suficientemente cerca para interactuar.
* **`player.js`**: Todo lo que hace tu personaje: movimiento en 8 direcciones, animaciÃ³n de pasos, duraciÃ³n del espadazo y las transiciones al cruzar los bordes hacia los cuartos norte, sur, este y oeste.
* **`npcs.js`**: Controla el comportamiento de los NPCs (como el del cuarto oeste) y sus futuras rutinas de movimiento o animaciones de entrada/salida.
* **`interactions.js`**: Maneja la tecla `E` (abrir/cerrar el cofre este) y todo el sistema de cuadros de diÃ¡logo letra por letra estilo *Undertale*.
* **`combat.js`**: La inteligencia de combate. Controla cada cuÃ¡nto dispara el enemigo del cuarto norte, la trayectoria de sus balas, el daÃ±o que recibes y el *respawn* en el Ãºltimo punto de guardado si te quedas sin corazones.
* **`renderer.js`**: El pintor. Toma los datos actuales de `state.js` y dibuja todo en pantalla en orden: menÃº de inicio, fondo de la sala, enemigos, objetos, personaje, corazones de vida, caja de diÃ¡logo y el mapa interactivo con `Tab`.

import { useEffect, useRef, useState } from 'react';
import { getMenuButtons, getMapLayout } from './game/constants';
import { loadGameAssets } from './game/assets';
import { createAudioManager } from './game/audio';
import {
  createInitialGameState,
  readSavedGame,
  startNewGame,
  loadSavedGame,
  teleportToRoom,
  returnToMenu,
  resizeGameScreen,
} from './game/state';
import { pointInRect } from './game/physics';
import { updatePlayer } from './game/player';
import { updateNpcs } from './game/npcs';
import {
  advanceDialogue,
  updateDialogue,
  handleInteractionKey,
} from './game/interactions';
import { updateCombat } from './game/combat';
import { drawGame } from './game/renderer';

export default function App() {
  const canvasRef = useRef(null);
  const gameRef = useRef(null);
  const [isPlaying, setIsPlaying] = useState(false);
  const returnToMenuRef = useRef(null);
  const mobileControlsRef = useRef(null);

  const [viewport, setViewport] = useState(() => ({
    width: window.innerWidth,
    height: window.innerHeight,
  }));
  const [isMobile, setIsMobile] = useState(
    () => window.innerWidth <= 880 || 'ontouchstart' in window
  );

  useEffect(() => {
    const handleResize = () => {
      const w = window.innerWidth;
      const h = window.innerHeight;
      setViewport({ width: w, height: h });
      setIsMobile(w <= 880 || 'ontouchstart' in window);

      if (gameRef.current) {
        resizeGameScreen(gameRef.current, w, h);
      }
      if (canvasRef.current) {
        canvasRef.current.width = w;
        canvasRef.current.height = h;
      }
    };

    window.addEventListener('resize', handleResize);
    return () => window.removeEventListener('resize', handleResize);
  }, []);

  useEffect(() => {
    const canvas = canvasRef.current;
    if (!canvas) return;
    const ctx = canvas.getContext('2d');
    if (!ctx) return;

    const assets = loadGameAssets();
    const audio = createAudioManager();
    const game = createInitialGameState();
    resizeGameScreen(game, window.innerWidth, window.innerHeight);
    canvas.width = game.width;
    canvas.height = game.height;
    gameRef.current = game;

    returnToMenuRef.current = () => {
      returnToMenu(game, setIsPlaying);
    };

    mobileControlsRef.current = {
      setKey: (key, isPressed) => {
        audio.startMusic();
        if (game.screen !== 'playing' || game.isMapOpen || game.dialogue.active) {
          game.keys[key] = false;
          return;
        }
        game.keys[key] = isPressed;
      },
      attack: () => {
        audio.startMusic();
        if (game.screen !== 'playing') return;
        if (game.dialogue.active) {
          advanceDialogue(game);
          return;
        }
        if (!game.isMapOpen && !game.isAttacking) {
          game.isAttacking = true;
          game.attackHasHit = false;
          game.attackFrame = 0;
          game.attackTimer = 0;
        }
      },
      interact: () => {
        audio.startMusic();
        if (game.screen !== 'playing') return;
        if (game.dialogue.active) {
          advanceDialogue(game);
          return;
        }
        if (!game.isMapOpen) {
          handleInteractionKey(game);
        }
      },
      toggleMap: () => {
        audio.startMusic();
        if (game.screen !== 'playing' || game.dialogue.active) return;
        game.isMapOpen = !game.isMapOpen;
        game.hoveredMapRoom = null;
      },
      toggleMute: () => {
        audio.startMusic();
        audio.toggleMute();
      },
      toggleGuide: () => {
        if (game.screen !== 'playing') return;
        game.showControlsGuide = !game.showControlsGuide;
      },
    };

    const getCanvasCoords = (e) => {
      const rect = canvas.getBoundingClientRect();
      const scaleX = game.width / rect.width;
      const scaleY = game.height / rect.height;
      return {
        mx: (e.clientX - rect.left) * scaleX,
        my: (e.clientY - rect.top) * scaleY,
      };
    };

    const handleKeyDown = (e) => {
      audio.startMusic();

      if (e.key.toLowerCase() === 'm') {
        audio.toggleMute();
        return;
      }

      if (e.key.toLowerCase() === 'h' && game.screen === 'playing') {
        game.showControlsGuide = !game.showControlsGuide;
        return;
      }

      if (game.dialogue.active) {
        e.preventDefault();
        advanceDialogue(game);
        return;
      }

      if (game.screen === 'menu') {
        if (e.key === 'ArrowUp' || e.key.toLowerCase() === 'w') {
          e.preventDefault();
          game.menuSelected = 0;
        } else if (e.key === 'ArrowDown' || e.key.toLowerCase() === 's') {
          e.preventDefault();
          if (readSavedGame()) game.menuSelected = 1;
        } else if (e.key === 'Enter' || e.key === ' ') {
          e.preventDefault();
          if (game.menuSelected === 0) {
            startNewGame(game, setIsPlaying);
          } else if (game.menuSelected === 1 && readSavedGame()) {
            loadSavedGame(game, setIsPlaying);
          }
        }
        return;
      }

      if (e.key === 'Tab') {
        e.preventDefault();
        if (!e.repeat) {
          game.isMapOpen = !game.isMapOpen;
          game.hoveredMapRoom = null;
        }
        return;
      }

      if (!game.isMapOpen && e.key.toLowerCase() === 'e') {
        if (handleInteractionKey(game)) {
          return;
        }
      }

      if (['ArrowUp', 'ArrowDown', 'ArrowLeft', 'ArrowRight'].includes(e.key)) {
        e.preventDefault();
      }
      game.keys[e.key.toLowerCase()] = true;
    };

    const handleKeyUp = (e) => {
      game.keys[e.key.toLowerCase()] = false;
    };

    const handleWindowBlur = () => {
      game.keys = {};
    };

    const handleMouseMove = (e) => {
      const { mx, my } = getCanvasCoords(e);

      if (game.screen === 'menu') {
        const menuButtons = getMenuButtons(game.width, game.height);
        if (pointInRect(mx, my, menuButtons.newGame)) {
          game.menuHovered = 'newGame';
          game.menuSelected = 0;
        } else if (pointInRect(mx, my, menuButtons.loadGame)) {
          game.menuHovered = 'loadGame';
          if (readSavedGame()) game.menuSelected = 1;
        } else {
          game.menuHovered = null;
        }
        return;
      }

      if (!game.isMapOpen) {
        game.hoveredMapRoom = null;
        return;
      }

      const { rooms: mapRooms } = getMapLayout(game.width, game.height);
      let found = null;
      for (const [roomKey, rect] of Object.entries(mapRooms)) {
        if (game.visitedRooms?.[roomKey] && pointInRect(mx, my, rect)) {
          found = roomKey;
          break;
        }
      }
      game.hoveredMapRoom = found;
    };

    const handleMouseDown = (e) => {
      audio.startMusic();
      const { mx, my } = getCanvasCoords(e);

      if (game.screen === 'menu') {
        const menuButtons = getMenuButtons(game.width, game.height);
        if (pointInRect(mx, my, menuButtons.newGame)) {
          startNewGame(game, setIsPlaying);
          return;
        }
        if (pointInRect(mx, my, menuButtons.loadGame) && readSavedGame()) {
          loadSavedGame(game, setIsPlaying);
          return;
        }
        return;
      }

      if (game.dialogue.active) {
        advanceDialogue(game);
        return;
      }

      if (game.isMapOpen) {
        const { rooms: mapRooms } = getMapLayout(game.width, game.height);
        for (const [roomKey, rect] of Object.entries(mapRooms)) {
          if (game.visitedRooms?.[roomKey] && pointInRect(mx, my, rect)) {
            teleportToRoom(game, roomKey);
            return;
          }
        }
        return;
      }

      if (!game.isAttacking) {
        game.isAttacking = true;
        game.attackHasHit = false;
        game.attackFrame = 0;
        game.attackTimer = 0;
      }
    };

    window.addEventListener('keydown', handleKeyDown);
    window.addEventListener('keyup', handleKeyUp);
    window.addEventListener('blur', handleWindowBlur);
    canvas.addEventListener('mousemove', handleMouseMove);
    canvas.addEventListener('mousedown', handleMouseDown);

    let animationFrameId;

    const loop = () => {
      if (game.screen === 'playing' && !game.isMapOpen) {
        if (game.dialogue.active) {
          updateDialogue(game);
        } else {
          if (game.saveNoticeTimer > 0) game.saveNoticeTimer -= 1;
          if (game.playerHitFlash > 0) game.playerHitFlash -= 1;
          if (game.northEnemy.hitFlash > 0) game.northEnemy.hitFlash -= 1;

          updatePlayer(game);
          updateNpcs(game);
          updateCombat(game);
        }
      }

      drawGame(ctx, game, assets);
      animationFrameId = requestAnimationFrame(loop);
    };

    loop();

    return () => {
      audio.stopMusic();
      window.removeEventListener('keydown', handleKeyDown);
      window.removeEventListener('keyup', handleKeyUp);
      window.removeEventListener('blur', handleWindowBlur);
      canvas.removeEventListener('mousemove', handleMouseMove);
      canvas.removeEventListener('mousedown', handleMouseDown);
      cancelAnimationFrame(animationFrameId);
    };
  }, []);

  const bindHoldKey = (key) => ({
    onPointerDown: (e) => {
      e.preventDefault();
      mobileControlsRef.current?.setKey(key, true);
    },
    onPointerUp: (e) => {
      e.preventDefault();
      mobileControlsRef.current?.setKey(key, false);
    },
    onPointerLeave: () => {
      mobileControlsRef.current?.setKey(key, false);
    },
    onPointerCancel: () => {
      mobileControlsRef.current?.setKey(key, false);
    },
  });

  const dpadBtnStyle = {
    width: '50px',
    height: '50px',
    backgroundColor: 'rgba(37, 37, 45, 0.78)',
    color: '#ffffff',
    border: '2px solid rgba(255, 255, 255, 0.85)',
    fontFamily: 'monospace',
    fontSize: '18px',
    fontWeight: 'bold',
    display: 'flex',
    alignItems: 'center',
    justifyContent: 'center',
    userSelect: 'none',
    WebkitUserSelect: 'none',
    WebkitTouchCallout: 'none',
    touchAction: 'none',
    padding: 0,
  };

  const hudBtnStyle = {
    height: '36px',
    padding: '0 10px',
    backgroundColor: 'rgba(20, 20, 24, 0.78)',
    color: '#ffffff',
    border: '2px solid rgba(255, 255, 255, 0.85)',
    fontFamily: 'monospace',
    fontSize: '14px',
    fontWeight: 'bold',
    cursor: 'pointer',
    display: 'flex',
    alignItems: 'center',
    justifyContent: 'center',
    userSelect: 'none',
    WebkitUserSelect: 'none',
    WebkitTouchCallout: 'none',
    touchAction: 'none',
  };

  //BLOQUEO DE CLICCK derecho
  useEffect(() => {
    const bloquearClicDerecho = (e) => {
      if (e.button === 2) {
        e.preventDefault();
        e.stopPropagation();
      }
    };

    const bloquearMenuContextual = (e) => {
      e.preventDefault();
      e.stopPropagation();
    };

    document.addEventListener('mousedown', bloquearClicDerecho, true);
    document.addEventListener('contextmenu', bloquearMenuContextual, true);

    return () => {
      document.removeEventListener('mousedown', bloquearClicDerecho, true);
      //document.removeEventListener('contextmenu', bloquearMenuContextual, true);
    };
  }, []);

  return (
    <div
      style={{
        position: 'fixed',
        inset: 0,
        width: '100vw',
        height: '100vh',
        overflow: 'hidden',
        margin: 0,
        padding: 0,
        touchAction: 'none',
        userSelect: 'none',
        WebkitUserSelect: 'none',
        WebkitTouchCallout: 'none',
      }}
    >
      {/* Pantalla completa del juego */}
      <canvas
        ref={canvasRef}
        width={viewport.width}
        height={viewport.height}
        style={{
          width: '100%',
          height: '100%',
          display: 'block',
          imageRendering: 'pixelated',
          cursor: 'pointer',
          touchAction: 'none',
        }}
      />

      {/* Botones flotantes superiores izquierdos encima del juego */}
      {isPlaying && (
        <div
          style={{
            position: 'absolute',
            top: '16px',
            left: '16px',
            display: 'flex',
            gap: '8px',
            zIndex: 10,
          }}
        >
          <button
            type="button"
            onClick={(e) => {
              e.currentTarget.blur();
              returnToMenuRef.current?.();
            }}
            title="Volver al menÃº"
            style={{ ...hudBtnStyle, width: '36px', padding: 0, fontSize: '18px' }}
          >
            â†
          </button>

          <button
            type="button"
            onClick={(e) => {
              e.currentTarget.blur();
              mobileControlsRef.current?.toggleGuide();
            }}
            title="GuÃ­a de controles (H)"
            style={{ ...hudBtnStyle, width: '36px', padding: 0, fontSize: '16px' }}
          >
            ?
          </button>

          {isMobile && (
            <>
              <button
                type="button"
                onClick={() => mobileControlsRef.current?.toggleMap()}
                style={hudBtnStyle}
              >
                MAPA
              </button>
              <button
                type="button"
                onClick={() => mobileControlsRef.current?.toggleMute()}
                style={{ ...hudBtnStyle, width: '36px', padding: 0 }}
              >
                â™ª
              </button>
            </>
          )}
        </div>
      )}

      {/* Controles tÃ¡ctiles flotantes en celular */}
      {isMobile && isPlaying && (
        <>
          <div
            style={{
              position: 'absolute',
              bottom: '74px',
              left: '16px',
              display: 'grid',
              gridTemplateColumns: '50px 50px 50px',
              gridTemplateRows: '50px 50px 50px',
              gap: '4px',

import { COLS, ROWS, ROOMS } from './constants';

function removeExteriorBlack(img) {
  const offCanvas = document.createElement('canvas');
  offCanvas.width = img.naturalWidth;
  offCanvas.height = img.naturalHeight;
  const ctx = offCanvas.getContext('2d');
  ctx.drawImage(img, 0, 0);

  const imgData = ctx.getImageData(0, 0, offCanvas.width, offCanvas.height);
  const data = imgData.data;
  const w = offCanvas.width;
  const h = offCanvas.height;

  const cellW = Math.floor(w / COLS);
  const cellH = Math.floor(h / ROWS);
  const visited = new Uint8Array(w * h);

  const isBlack = (x, y) => {
    const idx = (y * w + x) * 4;
    return data[idx] < 30 && data[idx + 1] < 30 && data[idx + 2] < 30;
  };

  for (let r = 0; r < ROWS; r++) {
    for (let c = 0; c < COLS; c++) {
      const x0 = c * cellW;
      const y0 = r * cellH;
      const x1 = Math.min(w, (c + 1) * cellW);
      const y1 = Math.min(h, (r + 1) * cellH);

      const queue = [];
      const pushIfBlack = (x, y) => {
        const pos = y * w + x;
        if (!visited[pos] && isBlack(x, y)) {
          visited[pos] = 1;
          queue.push(x, y);
        }
      };

      for (let x = x0; x < x1; x++) {
        pushIfBlack(x, y0);
        pushIfBlack(x, y1 - 1);
      }
      for (let y = y0; y < y1; y++) {
        pushIfBlack(x0, y);
        pushIfBlack(x1 - 1, y);
      }

      let head = 0;
      while (head < queue.length) {
        const cx = queue[head++];
        const cy = queue[head++];
        data[(cy * w + cx) * 4 + 3] = 0;

        if (cx > x0) pushIfBlack(cx - 1, cy);
        if (cx + 1 < x1) pushIfBlack(cx + 1, cy);
        if (cy > y0) pushIfBlack(cx, cy - 1);
        if (cy + 1 < y1) pushIfBlack(cx, cy + 1);
      }
    }
  }

  ctx.putImageData(imgData, 0, 0);
  return offCanvas;
}

  if (game.room !== 'top') return;

  const enemy = game.northEnemy;

  if (enemy.hp > 0) {
    enemy.shootTimer += 1;
    if (enemy.shootTimer >= 70) {
      enemy.shootTimer = 0;
      const bulletSize = 20;
      const startX = enemy.x + enemy.size / 2 - bulletSize / 2;
      const startY = enemy.y + enemy.size / 2 - bulletSize / 2;

      const targetX = game.x + DRAW_SIZE / 2 - bulletSize / 2;
      const targetY = game.y + DRAW_H / 2 - bulletSize / 2;
      const angle = Math.atan2(targetY - startY, targetX - startX);
      const bulletSpeed = 5;

      game.bullets.push({
        x: startX,
        y: startY,
        vx: Math.cos(angle) * bulletSpeed,
        vy: Math.sin(angle) * bulletSpeed,
        size: bulletSize,
      });
    }
  }

  const pBox = getPlayerBox(game);
  const remainingBullets = [];

  for (const b of game.bullets) {
    b.x += b.vx;
    b.y += b.vy;

    const bBox = { x: b.x, y: b.y, w: b.size, h: b.size };

    if (rectsOverlap(pBox, bBox)) {
      game.playerHp -= 1;
      game.playerHitFlash = 14;

      }
    } else if (

      b.x < game.width &&
      b.y > -b.size &&
      b.y < game.height
    ) {
      remainingBullets.push(b);

  // Si estÃ¡ en caminata automÃ¡tica (al entrar/salir de puerta o casa), el personaje se mueve solo
  if (game.autoWalk?.active) {
    dx = game.autoWalk.dx;
    dy = game.autoWalk.dy;
    game.autoWalk.frames -= 1;
    if (game.autoWalk.frames <= 0) {
      game.autoWalk.active = false;
    }
  } else {
    if (game.keys['arrowup'] || game.keys['w']) dy -= 1;
    if (game.keys['arrowdown'] || game.keys['s']) dy += 1;
    if (game.keys['arrowleft'] || game.keys['a']) dx -= 1;
    if (game.keys['arrowright'] || game.keys['d']) dx += 1;
  }

  game.isMoving = dx !== 0 || dy !== 0;

  if (game.isMoving && !game.isAttacking) {
    const key = `${dx},${dy}`;
    if (WALK_ANIMS[key]) {
      game.dirKey = key;
    }

    if (dy < 0) game.lastCardinal = 'up';
    else if (dy > 0) game.lastCardinal = 'down';
    else if (dx < 0) game.lastCardinal = 'left';
    else if (dx > 0) game.lastCardinal = 'right';

    const len = Math.hypot(dx, dy);
    const vx = (dx / len) * SPEED;
    const vy = (dy / len) * SPEED;

    const prevX = game.x;
    game.x += vx;
    if (hitsRoomObstacle(game, game.x, game.y)) {
      game.x = prevX;
    }

    const prevY = game.y;
    game.y += vy;
    if (hitsRoomObstacle(game, game.x, game.y)) {
      game.y = prevY;
    }

    game.animTimer += 1;
    if (game.animTimer >= 8) {
      game.animTimer = 0;
      game.animIndex = (game.animIndex + 1) % 3;
      // aquÃ­ para futuros implementos de sonido de caminata (pasos)
    }
  } else if (!game.isAttacking) {
    game.animIndex = 1;
    game.animTimer = 0;
  }

  const maxPosX = game.width - DRAW_SIZE;
  const maxPosY = game.height - DRAW_H;

  // Mantener dentro de los lÃ­mites de la pantalla (ya no se cruza por todo el borde)
  if (game.x < 0) game.x = 0;
  if (game.x > maxPosX) game.x = maxPosX;
  if (game.y < 0) game.y = 0;
  if (game.y > maxPosY) game.y = maxPosY;

  // Durante la caminata automÃ¡tica no volvemos a disparar portales ni puertas
  if (game.autoWalk?.active) return;

  const pBox = getPlayerBox(game);

  // 1. Revisar entrada o salida de casa (cuadro negro)
  const housePortal = getHousePortal(game.room, game.width, game.height);
  if (housePortal && rectsOverlap(pBox, housePortal)) {
    const targetRoom = housePortal.targetRoom;
    game.room = targetRoom;
    game.bullets = [];

    const destPortal = getHousePortal(targetRoom, game.width, game.height);
    if (housePortal.type === 'enter' && destPortal) {
      // Aparece frente a la salida interior y camina hacia arriba
      game.x = Math.round(destPortal.x + destPortal.w / 2 - DRAW_SIZE / 2);
      game.y = destPortal.y - DRAW_H - 12;
      startAutoWalk(game, 0, -1, 14);
    } else if (housePortal.type === 'exit' && destPortal) {
      // Aparece frente a la puerta de la casa en el exterior y camina hacia abajo
      game.x = Math.round(destPortal.x + destPortal.w / 2 - DRAW_SIZE / 2);
      game.y = destPortal.y + destPortal.h + 12;
      startAutoWalk(game, 0, 1, 14);
    }
    return;
  }

  // 2. Revisar puertas hacia otros cuartos exteriores
  const doors = getRoomDoors(game.room, game.width, game.height);
  for (const door of doors) {
    if (rectsOverlap(pBox, door) && isDoorUnlocked(game, door)) {
      game.room = door.targetRoom;
      game.bullets = [];
      game.visitedRooms[door.targetRoom] = true;
      if (door.connectorId) {
        game.visitedConnectors[door.connectorId] = true;
      }

      if (door.side === 'right') {
        game.x = 34;
        game.y = Math.round(game.height / 2 - DRAW_H / 2);
      } else if (door.side === 'left') {
        game.x = maxPosX - 34;
        game.y = Math.round(game.height / 2 - DRAW_H / 2);
      } else if (door.side === 'top') {
        game.x = Math.round(game.width / 2 - DRAW_SIZE / 2);
        game.y = maxPosY - 34;
      } else if (door.side === 'bottom') {
        game.x = Math.round(game.width / 2 - DRAW_SIZE / 2);
        game.y = 34;
      }

      if (door.targetRoom === 'bottom') {
        saveCheckpointAtSouth(game);
      }

      startAutoWalk(game, door.walkDir[0], door.walkDir[1], 14);
      return;
    }
  }
}

export function loadSavedGame(game, setIsPlaying) {
  const saved = readSavedGame();
  if (!saved) return;

  const spawn = getCenterSpawn(game.width, game.height);
  game.room = saved.room;
  game.x = Math.min(saved.x ?? spawn.x, Math.max(0, game.width - DRAW_SIZE));
  game.y = Math.min(saved.y ?? spawn.y, Math.max(0, game.height - DRAW_H));
  game.playerHp = MAX_PLAYER_HP;
  game.playerHitFlash = 0;
  game.dirKey = '0,1';
  game.lastCardinal = 'down';
  game.isAttacking = false;
  game.attackHasHit = false;
  game.attackFrame = 0;
  game.attackTimer = 0;
  game.isMapOpen = false;
  game.dialogue.active = false;
  game.keys = {};
  game.bullets = [];
  game.northEnemy.hp =
    typeof saved.northEnemyHp === 'number' ? saved.northEnemyHp : MAX_ENEMY_HP;
  game.northEnemy.hitFlash = 0;
  game.northEnemy.shootTimer = 0;
  game.rightSwitchPressed = Boolean(saved.rightSwitchPressed);
  game.visitedRooms = saved.visitedRooms || { left: true, [saved.room]: true };
  game.visitedConnectors = saved.visitedConnectors || {};
  game.autoWalk = { active: false, dx: 0, dy: 0, frames: 0 };
  game.checkpoint = { ...saved };
  game.screen = 'playing';
  setIsPlaying(true);
}

export function teleportToRoom(game, targetRoom) {
  const spawn = getCenterSpawn(game.width, game.height);
  game.room = targetRoom;
  game.visitedRooms[targetRoom] = true;
  game.x = spawn.x;
  game.y = spawn.y - 24;
  game.bullets = [];
  game.isAttacking = false;
  game.attackFrame = 0;
  game.isMapOpen = false;
  game.hoveredMapRoom = null;

  // Al teletransportarse desde el mapa, da unos pasos hacia abajo automÃ¡ticamente
  startAutoWalk(game, 0, 1, 14);

  if (targetRoom === 'bottom') {
    saveCheckpointAtSouth(game);
  }
}

export function resizeGameScreen(game, newWidth, newHeight) {
  game.width = newWidth;
  game.height = newHeight;

  game.x = Math.max(0, Math.min(game.x, newWidth - DRAW_SIZE));
  game.y = Math.max(0, Math.min(game.y, newHeight - DRAW_H));

  game.northEnemy.x = Math.round(newWidth / 2 - DRAW_SIZE / 2);
  game.eastChest.x = Math.round(newWidth * 0.68);
  game.eastChest.y = Math.round(newHeight / 2 - 24);
  game.rightSwitch.x = Math.round(newWidth * 0.52);
  game.rightSwitch.y = Math.round(newHeight * 0.28);
  game.westNpc.x = Math.round(newWidth * 0.22);
  game.westNpc.y = Math.round(newHeight / 2 - DRAW_H / 2);
}

export function returnToMenu(game, setIsPlaying) {
  game.screen = 'menu';
  game.isMapOpen = false;
  game.dialogue.active = false;
  game.isAttacking = false;
  game.attackFrame = 0;
  game.keys = {};
  setIsPlaying(false);
}
